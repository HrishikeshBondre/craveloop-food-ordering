# CraveLoop — Online Food Ordering SPA

Responsive React single-page food ordering assignment with Home, Menu, Cart, Checkout and Order Success views.

## Run
1. Install Node.js LTS: https://nodejs.org/
2. Extract this ZIP and open the folder in VS Code.
3. In the VS Code terminal run:
   `npm install`
   `npm run dev`
4. Open the local URL printed by Vite (usually http://localhost:5173).

## Build
`npm run build` creates the production site in `dist`.

## Deploy to Vercel
Push the folder to GitHub, import the repository in Vercel, use build command `npm run build` and output directory `dist`.

This is a front-end demo: orders and payment are simulated, not sent to a real restaurant or payment service. Food photos load from Unsplash and need internet access.
